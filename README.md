This is my personal website focused on my art and music. It has some fun features such as:

- Pulling data from Google Sheets to help assemble the [book drawings page](https://minttoothpick.com/book-drawings/). I wrote a blog post explaining how I developed this: [Creating proportional, equal-height image rows with CSS, 11ty, and Nunjucks](https://jeremyrobertjones.com/blog/proportional-equal-height-image-row-css-11ty-nunjucks/).
- A [shortcode to output an aspect-ratio-respecting image row component](https://github.com/minttoothpick/minttoothpick.com-2025/blob/0bd36ade71269ea63f3eb15940dfe92759e0765a/.eleventy.js#L48).
